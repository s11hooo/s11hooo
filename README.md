#### ⌘ &nbsp; 01 / AUTHENTICATION
##### 회원가입부터 로그인 상태 관리까지

개인·기업 회원가입과 로그인 기능을 구현하고,
로그인한 사용자를 식별해 개인별 기능으로 연결하는 기반을 마련했습니다.

- **회원가입 입력 검증**  
  필수 정보 누락과 비밀번호 확인 불일치를 검사하고,
  아이디·이메일 중복 여부를 확인하도록 구현했습니다.

- **가입 데이터의 연계 처리**  
  구직자 가입 시 회원 정보와 기본 구직자 프로필이 함께 생성되도록 구성하고,
  해당 작업을 하나의 트랜잭션으로 처리했습니다.

- **세션 기반 로그인 관리**  
  로그인 성공 시 회원 ID·사용자 이름·역할을 `HttpSession`에 저장하고,
  로그인 정보 조회와 로그아웃 처리를 구현했습니다.

- **처리 결과 구분**  
  가입 성공, 중복 정보, 로그인 실패 등의 결과를
  응답 코드와 메시지로 전달해 화면에서 안내할 수 있도록 했습니다.

**↳ 서비스에 연결한 부분**  
프로필·관심공고 등 개인별 기능에서 활용할 수 있는 사용자 식별 기반을 구현했습니다.

`Spring MVC` `HttpSession` `MyBatis` `Transaction`

<br>

#### ⇄ &nbsp; 02 / PUBLIC DATA INTEGRATION
##### 외부 채용정보를 서비스에서 활용할 수 있는 데이터로

한국장애인고용공단 **KEAD 채용정보 OpenAPI**를 연동하고,
수신한 데이터를 일이음의 채용공고 구조에 맞춰 저장하는 흐름을 구현했습니다.

- **API 호출과 XML 파싱**  
  Java HttpClient로 채용정보를 요청하고,
  XML 응답을 파싱해 서비스에서 사용할 객체로 변환했습니다.

- **페이지 단위 데이터 수집**  
  여러 페이지의 공고를 순차적으로 가져오고,
  응답 건수와 전체 건수를 기준으로 수집 종료 여부를 판단하도록 구성했습니다.

- **공고 데이터 변환**  
  직무명·지역·고용형태·급여·경력·학력·마감일을
  서비스의 필드와 코드 체계에 맞춰 변환했습니다.

- **데이터 저장·갱신**  
  수집한 공고를 DB에 저장하고,
  기존 공고는 갱신할 수 있도록 MyBatis 저장 로직을 연결했습니다.

- **정보의 확인 여부 구분**  
  외부 API에서 제공하지 않는 편의시설 정보는
  확인된 정보로 취급하지 않도록 접근성 정보의 확인 여부를 별도로 관리했습니다.

**↳ 서비스에 연결한 부분**  
외부 데이터 수신부터 변환·저장까지 연결해,
채용공고 조회와 추천 기능에서 사용할 데이터 기반을 마련했습니다.

`KEAD OpenAPI` `Java HttpClient` `XML Parsing` `Data Mapping`

<br>

#### ▤ &nbsp; 03 / DATABASE
##### 서비스 전체의 데이터 저장 기반 구성

일이음에서 사용하는 **전체 데이터베이스 테이블 제작**을 담당했습니다.
각 기능에서 필요한 데이터를 저장하고 연결할 수 있도록
회원·공고·구직 활동·커뮤니티 정보를 구성했습니다.

| 데이터 영역 | 관리하는 정보 |
| :--- | :--- |
| **회원·프로필** | 회원 정보와 구직자의 희망 직무·근무 조건 |
| **기업·채용공고** | 기업 정보와 직무·지역·급여·경력·학력 등의 채용 조건 |
| **관심공고·입사지원** | 회원과 채용공고를 연결하는 구직 활동 정보 |
| **맞춤 추천** | 추천 공고와 적합도 분석 결과 |
| **커뮤니티** | 게시글·댓글·신고 관련 정보 |

직접 담당한 인증·API 연동·관심공고 기능에서는
**DTO → Service → MyBatis Mapper → DB**로 이어지는
데이터 처리 흐름도 구현했습니다.

**↳ 서비스에 연결한 부분**  
개별 담당 기능을 넘어 서비스 전체 테이블을 제작해,
팀의 각 기능이 데이터를 저장하고 조회할 수 있는 공통 기반을 담당했습니다.

`MariaDB` `SQL` `MyBatis` `DTO`

<br>

#### ◇ &nbsp; 04 / SAVED JOBS
##### 로그인한 회원의 관심공고를 관리하는 기능

관심 있는 공고를 저장하고 다시 확인할 수 있도록
**관심공고 조회·등록·삭제 기능**을 구현했습니다.

- **세션 기준 회원 식별**  
  요청에서 받은 회원 번호 대신 로그인 세션의 회원 ID를 사용해
  관심공고 처리 대상을 결정했습니다.

- **중복 등록 확인**  
  회원 ID와 공고 ID를 함께 비교해
  같은 회원이 이미 저장한 공고인지 확인하도록 구현했습니다.

- **최신 공고 정보 조회**  
  관심공고에는 회원과 공고의 연결 정보를 저장하고,
  목록 조회 시 채용공고 테이블과 JOIN해 현재 공고 정보를 가져오도록 했습니다.

- **회원별 삭제 범위 지정**  
  삭제 SQL에 회원 ID와 공고 ID를 함께 적용해
  해당 회원이 저장한 관심공고만 삭제하도록 구성했습니다.

- **잘못된 요청 처리**  
  로그인 여부, 공고 ID 누락·형식 오류, 저장 실패를 구분해
  결과 메시지를 반환하도록 구현했습니다.

**↳ 서비스에 연결한 부분**  
관심공고 저장·삭제와 함께 회원별 데이터 구분,
중복 확인, 최신 공고 정보 조회까지 처리했습니다.

`HttpSession` `SQL JOIN` `MyBatis` `Input Validation`
